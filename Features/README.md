## Features

- 🎶 Browse devotional songs by category (Bhajan / Aarti / Kirtan / Singer / God)  
- ▶️ Play / Pause / Seek audio  
- ✅ Create and manage playlists  
- 💾 Download songs for offline playback (works without internet)  
- 🔍 Search songs, artists or gods  
- ❤️ Favorite songs / Like your favorites  
- 🔊 Background playback — continue listening while using other apps or when screen is off  
- 🛑 Smooth UI: clean layout, splash screen, simple navigation  
- 🎨 Theme support (you can later add light/dark or custom themes)  
- 🔄 Easy-to-extend structure: supports adding more gods, songs, videos or features in future  

### Future / Planned Features

- 📁 Categorized playlists (e.g. by God, mood, event)  
- 📺 Video devotional content inside app (audio + video)  
- 🔔 Notifications for new uploads or devotional reminders  
- 🌐 Multi-language support (Hindi / Punjabi / English)  
- 🧪 Dark mode / Theme toggle  
- 🔄 Sync across devices (with optional cloud backend)
